# سناریوی ویدئوی دمو (~۵ دقیقه)

قبل از ضبط:
- سکان را اجرا کنید (`start.bat`) و صفحه را در حالت دسکتاپ بزرگ باز کنید.
- برای سناریوی ۵۰۰، متغیر را موقتاً پاک کنید یا یک برنامه‌ی تازه دیپلوی کنید. برای سناریوی حافظه، ۲–۳ دقیقه قبل از ضبط:
  `for /l %i in (1,1,7) do curl -s "https://cafeland-sokan.liara.run/admin/leak?mb=50" & timeout /t 20`
- در ویدئو سورس کد نشان ندهید؛ خروجی و رفتار را نشان دهید.

| زمان | چه نشان دهید | چه بگویید |
|---|---|---|
| ۰:۰۰–۰:۳۰ | صفحه‌ی اول: اعتبار تیم، پایش خودکار، بودجه‌ی LLM، پیشنهادها | «سکان همکار فنی صاحب سایت روی لیاراست: راه‌اندازی، پایش، عیب‌یابی و رفع مشکل؛ هر تغییری فقط با تأیید شما.» |
| ۰:۳۰–۱:۴۵ | **راه‌اندازی اولیه**: «پروژه‌ی … را روی لیارا بالا بیاور» → کارت تحلیل و پیشنهاد پلن با قیمت → کارت تأیید ساخت → (اشاره به ساخت خودکار شبکه) → کارت دیپلوی → لاگ زنده‌ی build → تست سایت | «دستیار پروژه را می‌خواند، ارزان‌ترین پلن مناسب را با قیمت واقعی API پیشنهاد می‌دهد، پیش‌نیازها را خودش تشخیص می‌دهد و بعد از انتشار، خود سایت را تست می‌کند.» |
| ۱:۴۵–۳:۰۰ | **خطای ۵۰۰**: «سایتم ارور ۵۰۰ می‌ده» → تایم‌لاین مراحل → گزارش عیب‌یابی (۹۹٪، شواهد را باز کنید) → دستیار مقدار را می‌پرسد → مقدار → کارت تأیید با مقدار پوشانده → اجرا → «سایت با کد ۲۰۰ پاسخ داد» | «علت از روی شواهد واقعی پیدا شد: خط لاگ، تنظیمات برنامه و پاسخ سایت. CPU و RAM رد شدند. دستیار رمز را حدس نمی‌زند و بعد از اجرا نتیجه را دوباره بررسی می‌کند.» |
| ۳:۰۰–۴:۰۰ | **کندی/نشت حافظه**: هشدار سایدبار یا «سایتم سنگین شده» → روند RAM روی نمودار با خط سقف پلن → کارت ری‌استارت → «RAM از ۳۸۵MB به ۳۳MB رسید» | «ری‌استارت مسکّن است؛ دستیار صادقانه می‌گوید ریشه در کد است و ارتقای پلن را هم به‌عنوان گزینه با هزینه نشان می‌دهد.» |
| ۴:۰۰–۴:۳۰ | داشبورد سمت چپ: سیاست‌های خودکار (روشن کردن یکی با تأیید)، تب «گزارش عملیات» | «خودکارسازی فقط با تأیید دائمی خود کاربر؛ هر اقدام با عامل و نتیجه ثبت می‌شود.» |
| ۴:۳۰–۵:۰۰ | تب «محدودیت‌های API» + اشاره به MCP | «هر چیزی که API لیارا اجازه نمی‌دهد صریحاً اعلام می‌شود با راه جایگزین. همین ابزارها از طریق MCP در Claude/Cursor هم در دسترس‌اند و آنجا هم بدون تأیید انسان هیچ تغییری اعمال نمی‌شود.» |
